# 書体

本文と見出しの書体と、その配り方。

## 概要・提供価値

本文と見出しを Noto Sans JP で出す。書体はページで使う字だけを切り出した 1 ファイルにして、サイトと同じドメインから配る。閲覧者のブラウザは外の書体の配信に接続せず、書体のために読み込むファイルも 1 つで済む。

## 背景・解決する課題

- 日本語の書体をそのまま読むと、字の範囲ごとのファイルが 1 書体で 100 個以上になり、`@font-face` だけで HTML が数百 KB になる（`astro.config.ts` の注釈）
- 書体を外の配信（Google Fonts の `<link>`）から読むと、字の範囲ごとのファイルと、外のドメインへの接続が増える（[テンプレートを作ったときの記録の「検討した他の案」](https://github.com/junkisai/web-site-template/blob/aaa2cbbdb77e2447ac00427379344e434e7ee40a/docs/design-docs/20261031_web-site-template.md#検討した他の案)）
- テンプレートのもとになった案件で足した仕組みのうち、中身に依存しないもの（日本語の書体を使う字だけ切り出す）として切り出した（[product.md の「解決する課題」](../product.md#解決する課題)）

## 対象ユーザー・スコープ

- 対象ユーザー・役割: 閲覧者。ページの文言を書くテンプレートの利用者
- 対象の画面・URL: すべてのページ
- できる操作: テンプレートの利用者がサイトのソースに書いた字は、書体に入る
- 対象の範囲: 本文と見出しの書体・太さ・書体に入れる字・入っていない字の出し方・書体の配り方
- 対象外: なし

## ゴール・成功条件

- ページで使う字が、本文も見出しも Noto Sans JP で出る
- 閲覧者のブラウザが、書体のために外のドメインへ接続しない
- 配る書体のファイルが 1 つで済む
- 測定指標は決まっていない

## 振る舞い

- 本文と見出しは Noto Sans JP で出す。太さは本文 500・強める字 700・見出し 800 で、500〜800 の範囲を 1 つの書体のファイルで持つ
- 書体は、サイトをビルドしたときに取ってきて、**サイトと同じドメインから配る。** 閲覧者のブラウザが外の書体の配信に接続することはない
- 配る書体は、**ページで使う字だけを切り出した 1 ファイル**
- 書体に入っていない字は、その字だけ代わりの書体で出す。代わりの書体は Hiragino Sans → Hiragino Kaku Gothic ProN → 端末の sans-serif の順

## 業務ルール・制約

- **書体に入れる字:** `apps/site/src/` の `.astro` と `.ts` に書かれた字（注釈の中の字は除く）と、ASCII の印字できる字すべて
- 書体に入るのはソースに書いた字だけ。ソースの外から来る字（CMS などのデータ）を Noto Sans JP で出したくなったら、この要件を変える変更として扱う
- 閲覧者のブラウザから外の書体の配信に接続しない（[site.md の「外部への接続」](site.md#外部への接続)）

## 状態遷移

なし

## 例外・境界条件

- ソースに書いていない字（CMS などから来る字を含む）→ その字だけ代わりの書体で出る
- 開発中に新しい字を書いた → 開発サーバーを立ち上げ直すまで書体に入らない（[runbooks/development.md の「開発サーバー」](../runbooks/development.md#開発サーバー)）
- ビルドのときに書体を取ってこられない → どうなるかは確かめていない（[未確認事項](#未確認事項)）

## 受け入れ条件

- ビルドの出力（`_astro/fonts/` の下）に、書体のファイルが 1 つだけある
- 出力の HTML が、外の書体の配信（Google Fonts など）を参照していない
