# 画面に入ったら出す動き

要素が画面に入ったときに出す動きと、動きを出さない条件。

## 概要・提供価値

テンプレートの利用者は、要素が画面に入ったときに「出る前」から「出たあと」の見た目に切り替わる動きを、要素ごとに付けられる。動きを減らす設定にしている閲覧者や JS が動かない環境には動きを出さず、最初からすべての内容を見せる。

## 背景・解決する課題

- テンプレートのもとになった案件で足した仕組みのうち、中身に依存しないもの（画面に入ったら出す動き）として切り出した（[design doc の「背景」](../design-docs/20261031_web-site-template.md#背景)）
- 「出る前」に要素を隠すスタイルを、動きを出すときだけ当てる。こうして、JS が動かない・動きを減らす設定の環境でも、最初から全部見えるようにしている（[design doc の「JS」](../design-docs/20261031_web-site-template.md#js)、`base-layout.astro` の注釈）
- 動きを止めた状態で表示を確かめられるよう、URL で動きを止める指定を持つ

## 対象ユーザー・スコープ

- 対象ユーザー・役割: 閲覧者（動きを減らす設定にしている人・JS が動かない環境の人を含む）。動きを付けるテンプレートの利用者。動きを止めて表示を確かめる人
- 対象の画面・URL: 動きを付けた要素があるページ。テンプレートでは、トップページの見出しに付けている
- できる操作: テンプレートの利用者は、要素ごとに動きを付けるかと、出る前・出たあとの見た目を決める。閲覧者は OS やブラウザの設定で動きを減らせる。URL に `#still`・`?still` を付けると動きを止められる
- 対象の範囲: 画面に入ったときに見た目を切り替える動き。ページの中のリンクの滑らかなスクロール
- 対象外: なし

## ゴール・成功条件

- 動きを出すときも出さないときも、ページの内容がすべて見える
- 動きを減らす設定にしている閲覧者には、動きを出さない
- 測定指標は決まっていない

## 振る舞い

### 出すとき

- 印を付けた要素は、画面の下から 15% の線まで入ったときに「出たあと」の見た目になる
- 1 度出た要素は、画面から外れても戻さない
- 出る前と出たあとにどう見えるかは、要素ごとに決める
- 動きを出すときだけ、ページの中のリンクで滑らかにスクロールする

### 出さないとき

次のどれかに当たるときは動きを出さず、**最初からすべての内容が見える。**

- JS が動かない
- OS やブラウザで、動き（視差効果）を減らす設定にしている
- URL に `#still` がある、またはクエリに `still` がある（`?still`・`&still`）。動きを止めた状態で確かめるときに使う

## 業務ルール・制約

- 「出る前」に要素を隠すのは、動きを出すときだけ。動きを出さないときに、隠れたままの要素を作らない

## 状態遷移

動きを出すときの、印を付けた要素の状態。動きを出さないときは「出る前」が無く、最初から見えている。

| 状態 | 見え方 | 次の状態へ移る条件 |
| --- | --- | --- |
| 出る前 | 要素ごとに決めた「出る前」の見た目（隠すなど） | 画面の下から 15% の線まで入る。画面に入ったかを判定できないブラウザでは、ページを開いてすぐ |
| 出たあと | 要素ごとに決めた「出たあと」の見た目 | 移らない。画面から外れても「出る前」に戻さない |

## 例外・境界条件

- 画面に入ったかを判定できないブラウザ → 印を付けた要素をすべて、すぐに「出たあと」にする
- JS が動かない・動きを減らす設定・`#still`・`?still` → 動きを出さず、最初からすべて見える

## 受け入れ条件

- 動きを減らす設定・`#still`・`?still`・JS を切った状態のどれでも、トップページの見出しが最初から見えている
- 動きを出す状態で、印を付けた要素が画面に入ると「出たあと」の見た目になり、画面から外れても戻らない

## 実装から読み取れる現状・未確認事項

### 実装から読み取れる現状

- **動きを出すかは、ページを開いたときに 1 度だけ決まる。** 開いたあとに動きを減らす設定や URL の `#still` を変えても、開き直すまで切り替わらない。これが意図されたものかは確かめていない
